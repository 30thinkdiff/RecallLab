# RecallLab · 记忆实验室

本地优先、AI 可选的主动回忆工具。当前开发分支 **V0.5.2 · 来源锁定的知识单元制卡与容量保护**。依赖未合并的 [PR #12](https://github.com/30thinkdiff/RecallLab/pull/12) → [#11](https://github.com/30thinkdiff/RecallLab/pull/11)，本轮独立PR及实际验证进度见[检查点记录](docs/V052_CHECKPOINTS.md)，不自动合并。

## 直接体验

打开 <http://127.0.0.1:5173>，无需构建或运行技术测试。

1. 导入资料 → 预览并确认。支持 JSON/CSV/TSV/TXT/Markdown、中文 PDF、本地中英文 OCR。
2. 在“今日复习”设置项目预算（例如每天 30 分钟）、目标日期、优先级与新题上限。
3. 开始今日计划或只学新题 → 独立回忆 → 揭晓并人工核对 → 保存，查看下次安排。
4. 随时暂停，之后继续原计划；第二天查看新到期任务，不必反复从头刷完整个题库。

没有合适题干的知识陈述会保留为待完善内容，不把答案复制进题面。项目内可批量完善，原答案和来源不丢失。重新 OCR 前保护未保存编辑，OCR 初始化或识别失败时保留可用原生文字。

## 可选 AI 辅助整理

保存资料 → 点击“AI 辅助整理” → 选择学习目标、模型及“分知识整理” → 检查发送范围并主动同意 → 预览候选/修改评分要点 → 人工确认 → 开始学习。已有题目也可建议要点、完善题干和检查质量。

本机服务/模型状态自动检测，提供明确同意后的会话启动与已有模型持久保存入口，不自动下载或设常驻服务。候选和编辑自动保存在本机，刷新/重开可继续，确认前不写题库。按章节检查尚无候选的单元，可标记暂不制卡；改动一条只撤销该条核对。相同答案的疑似重复集中比较，必需与可选要点不直接混合。

AI 默认关闭，Mock 明确只是模拟；支持本机 Ollama 和兼容接口。密钥仅保留当前页面进程，不写本地存储/备份；外部服务每次需主动选择。原文背诵直接保留引用原文，已有标准答案不被 AI 覆盖；缺失引用不能保存。逐字来源匹配不等于语义正确，生成内容必须人工核对。

## 评价与调度

- 使用稳定版 ts-fsrs **5.4.2**，本地运行。目标保持率 **0.90 是通用初始设置**，没有训练个人参数。
- 无提示、揭晓前确实尝试且人工核对全部必需内容正确，按回忆难度 Hard/Good/Easy，默认 Good。
- 明确失败或完整复述遗漏必需内容使用 Again；五级主观感受单独保存，高自评不会覆盖实际错误。
- 有提示、直接看答案或未核对，不更新长期状态，安排无提示复测；跳过不推断遗忘。临时加练与传统完整轮次保留练习记录，不自动更新 FSRS。
- 有必需要点时支持逐项人工核对：正确/遗漏/错误/无法确认；核对草稿暂停、刷新后保留，历史保存当时每项结果。也支持简洁整体判断，高自评不能覆盖要点汇总。
- 口头回忆仍是自报，输入回答后由用户人工核对；系统未自动验证。统计分开这些来源，不把熟悉感画成客观记忆概率。
- 当前题目实质性更正会建立新学习状态，旧成绩隔离；纯格式变化经内容校验可保留状态。历史事件、修订和原文不被追溯改写。

计划优先到期→无提示复测→重点→适量新题。预算按每题约 2 分钟估算配额，默认每天最多 10 道新题，可设置；不是测得的实际专注时长。目标日前 7 天优先同级薄弱内容，提前练习不改变长期安排。

## 数据安全与兼容

日常数据保存在当前浏览器的 IndexedDB **RecallLab / schema v7**。新增记忆状态和调度日志，保留 v1/v2/v3/v4 定义，旧历史不回填成 FSRS 成绩。首次升级先按页面保存备份，升级有事务保护副本与回滚。

V0.5.2 的正式 v7 迁移先保护 v6 原始副本，保留 v1—v6、原始事件和 FSRS；不会给旧历史补造成绩。草稿和关键操作在事务内检查基础版本，恢复重签草稿令牌，旧页不能静默覆盖。兼容 v1—v6 普通备份；旧程序不支持编辑升级后的数据库。

备份仍完整保留来源、AI原始建议、确认、修订、学习事件及调度。较大且去重有效时采用新文件格式v2，以完全相同字符串的可逆共享降低文件大小，**不删除或改写历史，也不压缩数据库本身**；旧版不能恢复新格式。普通JSON文件/逻辑展开上限128MiB，去重文件限50MiB、展开限128MiB并校验完整性；超过上限不冒充可安全恢复。一次公开规模实测逻辑52.28MiB→文件31.31MiB，恢复一致。备份不加密，用户需妥善保管；题库追加导入不能与替换式完整恢复混用。

文档、OCR、FSRS 都在本地运行，无需账号、AI 密钥、云服务或付费 API。原文件和 OCR 图像不保存，保留提取文字及来源；请保留原文件并定期下载备份。更换浏览器、端口或无痕配置使用不同存储空间。

发布版首次完成资源缓存后可离线重新打开同一地址；核心页面/调度预缓存，PDF/OCR 资源用过后按需缓存，未缓存的资源不保证离线首次可用。开发预览不安装缓存。

24份实测中分知识方案保留全部74项参考内容，但仍有13个题干需工程建议修改；原文保留不代表模型理解。三类任务实测AI填写文字更少、操作与等待更多，尚未证明真人总准备成本下降。参考和工程审阅均非独立真人金标准，优先继续改善制卡与审核。

## 当前边界

没有 AI 自动评分、个体参数优化、账户或云同步。人工核对仍可能出错；小样本观察不能代表长期保持。复杂 PDF 排版、表格、公式与模糊 OCR 需核对；无直接 DOCX 或交互解密。
主回归为 Chromium 桌面和基本手机布局，另有 Firefox 专项矩阵；具体运行结果见 PR 和测试文档。Windows/macOS、WebKit 和所有教材版式未完成验证。

## 工程与自动验证

Ubuntu 22.04；Node.js 20.19+（验证 20.20.2）、npm 10+。

```bash
npm ci
npm run dev
```

若服务器已启动，不重复启动。工程侧负责：

```bash
npm run check
npm run test:e2e
npm run test:production
npm run test:firefox
npm run test:summary
npm audit
```

自动化仅使用公开虚构资料，主浏览器测试固定 **5174 / RecallLab-test**，发布文件资源在 5175 测试；临时浏览器配置不访问日常配置。CI 上传与 SHA 对应的 HTML/JSON/JUnit 报告及失败证据，排除浏览器配置目录。

React、TypeScript、Vite、Dexie、Zod、Papa Parse、PDF.js、Tesseract.js、ts-fsrs、Vitest、Playwright；调度、学习、导入及 PDF/OCR 按需加载。
