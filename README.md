# RecallLab · 记忆实验室

An Evidence-Driven Adaptive Learning System.

以自己的学习资料为来源，通过主动回忆与可追溯的学习记录练习知识。
核心功能在本地运行，不需要登录、数据库服务器或 AI 密钥。

## 本地运行

Ubuntu 22.04，Node.js 20.19+（本机验证版本 20.20.2）、npm 10+，现代浏览器。

```bash
cd /home/hhd/recalllib
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>，支持热更新。无需 Docker、数据库服务器或登录。
请固定使用这个地址；浏览器数据按协议、主机名和端口隔离。

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## 已实现 · M0 / M1

- 创建、编辑、删除学习项目；设置目标、日期与每日时间计划。
- 手工添加、编辑、删除问答题；支持核对要点、逐条提示、来源、助记与易混提醒。
- 快速回忆或输入作答；揭晓前不显示答案；揭晓后锁定作答证据。
- 人工核对结果与 0–4 五级主观评价分别保存，支持跳过。
- IndexedDB 持久化题库、原始作答、提示记录、信心、用时与学习事件。
- 刷新后继续当前学习；关闭并重开同一浏览器仍保留数据。
- 学习概览、最近自评分布、历史详情和项目筛选；桌面及手机布局。

没有自动评分、FSRS 调度、AI、文件导入、导出、账户或云同步。
不会将主观评分解释成正确率或记忆概率。

## 体验一个完整闭环

1. 打开首页，点击“创建项目”，填写名称并保存。
2. 点击“添加问答题”，填写问题、标准答案，可添加逐行提示和核对要点。
3. 添加 10 道题，点击“开始学习”。
4. 选择快速回忆并点击“我已尝试回忆”，或切换“输入作答”写下答案。
5. 可逐条查看提示，再揭晓答案；选择人工核对结果和主观评价。
6. 保存并进入下一题。最后一题保存后显示本轮完成。
7. 在“学习记录”展开详情，查看原始作答、提示、评分来源和当时的答案。
8. 刷新或关闭浏览器，再用同一浏览器、同一地址打开，核对题库和记录是否仍在。

中途离开可回到项目点击“继续学习”；输入内容自动保存。尚未点击保存的揭晓后评分选择不会持久化。

## 数据存储与边界

数据保存在浏览器 IndexedDB 的 `RecallLab` 数据库中，不上传服务器。
请使用普通浏览窗口、固定浏览器配置和 <http://127.0.0.1:5173>。
换成 `localhost`、其他端口、无痕窗口或其他浏览器，会使用不同的存储空间。
清除网站数据、删除浏览器配置或存储被浏览器回收可能丢失记录；当前尚无导出备份功能。
Local-first 指核心数据不依赖远程服务，当前没有 Service Worker 离线安装功能。

“删除”使用归档方式：项目或题目从工作台隐藏，已有事件及答案快照留存。
删除项目后其记录不再显示于工作台，M1 暂无恢复入口。
题目编辑会增加修订号；已开始的学习轮次与历史事件保留旧快照，下一轮使用新内容。
进行中的轮次暂不支持删除单题，请完成后再删。

## 自动化验证

```bash
npm run check                 # 类型、Lint、格式、单元/组件测试、生产构建
npx playwright install chromium
npm run test:e2e              # 真实浏览器验收
npm run preview               # 可选：构建后在 127.0.0.1:4173 预览
```

首次安装 Chromium 需要联网。若提示缺少浏览器系统库，可按提示安装依赖：
`npx playwright install --with-deps chromium`（可能需要管理员权限，不是运行应用的必要条件）。
端到端测试使用独立浏览器配置，不接触你日常浏览器的数据；会自行启动开发服务器或复用正在运行的 5173 端口。
预览端口与开发端口的数据分开。

## 工程结构与文档

- `src/domain`：数据模型、输入校验、事件构建。
- `src/persistence`：版本化 Dexie 数据库和事务式仓库。
- `src/features`：项目与题目表单、工作台、学习流程。
- `src/components`：弹窗、错误边界、异步操作反馈。
- `tests/e2e`：Playwright 的 10 题闭环、CRUD、重启与手机验收。
- [产品规格](docs/PRODUCT_SPEC.md)、[架构说明](docs/ARCHITECTURE.md)。
- [进度与已知限制](docs/PROGRESS.md)、[变更记录](CHANGELOG.md)、[M0/M1 交付报告](docs/DELIVERY_M0_M1.md)。

React 19、TypeScript 严格模式、Vite 7、Dexie、Zod、Vitest 和 Playwright。
为控制首轮依赖和维护成本，使用原生 CSS 与原生 dialog，暂未引入 Tailwind、路由框架和大型组件库。
`package-lock.json` 固定实际依赖，使用 `npm ci` 复现安装；无需全局升级 Node.js 或 npm。

工作约定见 [AGENTS.md](AGENTS.md)：每轮先检查 `pwd` 和 Git 状态，在现有目录增量开发。
