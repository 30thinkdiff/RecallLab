# RecallLab · 记忆实验室

An Evidence-Driven Adaptive Learning System.

本地优先、AI 可选的主动回忆学习工具。当前版本 **0.2.0 · 第二轮 A–E**，在 M0/M1 基础上加入知识版本、可更新轮次、冲突保护、题目历史和备份恢复。等待用户体验及独立审查，未发布稳定版。

## 启动

Ubuntu 22.04，Node.js 20.19+（验证版本 20.20.2）、npm 10+，现代浏览器。

```bash
cd /home/hhd/recalllib
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>，支持热更新。无需登录、Docker、数据库服务器或 API 密钥。
若服务器已运行，直接打开地址，不必重复启动。

**已有 M0/M1 数据**：首次打开先显示升级前备份页。下载 JSON 并确认保存后再升级；迁移事务内还会保留一份原始保护副本。升级失败会回滚，不自动清空原库。请固定使用同一浏览器配置和上述地址。

## 已实现

- 项目及问答题管理；逐条提示、核对要点、来源、助记和易混提醒。
- 快速回忆或输入作答、揭晓前信心、人工核对、五级主观评价、跳过和持久化历史。
- 不可变题目修订：格式性修改、澄清、实质性更正、知识替换；记录修改原因和版本差异。
- 实质性更正不继承旧成绩；只有用户明确声明不改变学习要求，才保留此前有效证据。
- 新题可选择加入本轮或下轮再学；更新剩余题目、查看剩余、结束和重新开始一轮。
- 当前题目更新或归档时暂停旧评分；保留原始输入副本后载入最新版或移除归档任务。
- 多标签页通过草稿版本检查防止静默覆盖；本页快速输入串行保存，冲突可保留副本并载入最新草稿。
- 题目中心展示全部历史、修订时间线、差异、当前有效统计、实际次数图表与暂存作答。
- 完整 JSON 导出、校验预览、事务式替换恢复、失败回滚和恢复前副本；支持 v1 备份。
- 归档项目和题目的查看及恢复。

没有 FSRS、AI、PDF 提取、自动语义评分、账户、云同步或复杂记忆模型。人工核对和主观评分分别保存，不表示系统独立验证的正确率或记忆概率。

## 五个重点体验场景

1. **纠正错误答案**：先练习一道题，再编辑标准答案，保留默认“实质性更正”并填写原因。点击题目标题，旧事件仍显示旧答案，当前有效统计从零开始。
2. **学习中加题**：有两题时开始学习，在另一页新增题目。回学习页选择“加入本轮剩余练习”或“下轮再学”；当前作答保持不变。
3. **当前题目更新**：在学习页输入，另一页修改该题。旧页面暂停揭晓和评分，点击“保留输入并载入最新版”重新作答；旧输入可在题目详情的暂存副本中查看。
4. **两标签页竞争**：同一学习地址开两页同时输入。干净页面会采用观察到的新草稿；竞争写入被拒绝时显示冲突，保留本页输入，不静默覆盖。揭晓后两页都不能再改此前证据。
5. **题目历史与恢复**：点击题目标题，比较历史全部与当前有效统计，展开事件和修订。到“备份与恢复”导出；恢复前先看文件名、日期和数量，明确确认后整体替换。

归档当前题目不生成跳过或答错事件。结束本轮保留已完成事件；重新开始只建立新轮次，不清除学习历史或重置记忆状态。

## 本地数据

日常数据保存在当前浏览器 origin 对应的 IndexedDB **RecallLab**，schema v2，不上传服务器。
`localhost`、其他端口、其他浏览器或无痕窗口使用不同存储空间；清除网站数据可能丢失记录，请定期导出备份。

普通完整导出包含项目（含归档）、知识单元、题库、不可变修订、学习轮次、原始事件和暂存作答。自动保护副本为冗余的历史数据库快照，单独保留、可单独下载，避免递归扩大普通备份。恢复前副本也在本地同一数据库里，不能替代外部下载备份。

旧版本未知修改性质时采取保守隔离，不推断其语义等价。已保存事件不会被迁移或题目编辑追溯改写。揭晓后尚未提交的评分选择不自动保存；已保存的题库、作答草稿和事件可在刷新及重开浏览器后恢复。

## 检查与调试

```bash
npm run check               # 夹具复现、类型、Lint、格式、单元/组件测试、构建
npx playwright install chromium
npm run test:e2e            # 全部真实浏览器验收
npm run test:e2e:ui         # 交互式测试
npm run test:e2e:debug      # 单步调试
npm run test:report         # 阅读 HTML 报告
npm run test:summary        # 文本摘要与失败原因
npm run fixtures:check     # 验证公开虚构夹具可复现
npm run fixtures           # 重新生成公开虚构 JSON，不写任何浏览器数据库
```

浏览器首次安装需要联网；若缺系统库，可按提示运行 `npx playwright install --with-deps chromium`（可能需要管理员权限）。应用本身不依赖 Playwright。

自动测试使用独立 **5174** 端口、**RecallLab-test** 数据库和临时浏览器配置，不复用日常服务器，不访问真实学习数据，无生产清库按钮。测试 JSON、截图和报告仅包含公开虚构资料。

CI 自动检查并保留关联 Commit SHA 的 HTML/JSON/JUnit 报告，失败时附截图和 Trace。具体命令、隔离方式、A–N 用例映射见 [测试说明](docs/TESTING.md)。
