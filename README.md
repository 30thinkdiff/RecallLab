# RecallLab · 记忆实验室

本地优先、AI 可选的主动回忆工具。当前 **V0.4 · 基于真实学习证据的间隔复习**，等待体验与独立审查，未宣称效果最优。

## 直接体验

打开 <http://127.0.0.1:5173>，无需构建或运行技术测试。

1. 导入资料 → 预览并确认。支持 JSON/CSV/TSV/TXT/Markdown、中文 PDF、本地中英文 OCR。
2. 在“今日复习”设置项目预算（例如每天 30 分钟）、目标日期、优先级与新题上限。
3. 开始今日计划或只学新题 → 独立回忆 → 揭晓并人工核对 → 保存，查看下次安排。
4. 随时暂停，之后继续原计划；第二天查看新到期任务，不必反复从头刷完整个题库。

没有合适题干的知识陈述会保留为待完善内容，不把答案复制进题面。项目内可批量完善，原答案和来源不丢失。重新 OCR 前保护未保存编辑，OCR 初始化或识别失败时保留可用原生文字。

## 评价与调度

- 使用稳定版 ts-fsrs **5.4.2**，本地运行。目标保持率 **0.90 是通用初始设置**，没有训练个人参数。
- 无提示、揭晓前确实尝试且人工核对全部必需内容正确，按回忆难度 Hard/Good/Easy，默认 Good。
- 明确失败或完整复述遗漏必需内容使用 Again；五级主观感受单独保存，高自评不会覆盖实际错误。
- 有提示、直接看答案或未核对，不更新长期状态，安排无提示复测；跳过不推断遗忘。临时加练与传统完整轮次保留练习记录，不自动更新 FSRS。
- 口头回忆仍是自报，输入回答后由用户人工核对；系统未自动验证。统计分开这些来源，不把熟悉感画成客观记忆概率。
- 当前题目实质性更正会建立新学习状态，旧成绩隔离；纯格式变化经内容校验可保留状态。历史事件、修订和原文不被追溯改写。

计划优先到期→无提示复测→重点→适量新题。预算按每题约 2 分钟估算配额，默认每天最多 10 道新题，可设置；不是测得的实际专注时长。目标日前 7 天优先同级薄弱内容，提前练习不改变长期安排。

## 数据安全与兼容

日常数据保存在当前浏览器的 IndexedDB **RecallLab / schema v4**。新增记忆状态和调度日志，保留 v1/v2/v3 定义，旧历史不回填成 FSRS 成绩。首次升级先按页面保存备份，升级有事务保护副本与回滚。

完整 JSON 备份包含调度、来源、修订和事件，兼容 v1/v2/v3；恢复旧备份没有调度成绩时，从新评价开始。恢复前保护当前完整数据。题库导入只是追加，不能与替换式完整恢复混用。

文档、OCR、FSRS 都在本地运行，无需账号、AI 密钥、云服务或付费 API。原文件和 OCR 图像不保存，保留提取文字及来源；请保留原文件并定期下载备份。更换浏览器、端口或无痕配置使用不同存储空间。

## 当前边界

没有 AI 自动评分、个体参数优化、账户或云同步。人工核对仍可能出错；小样本观察不能代表长期保持。复杂 PDF 排版、表格、公式与模糊 OCR 需核对；无直接 DOCX 或交互解密。
主回归为 Chromium 桌面和基本手机布局，Windows/macOS、Firefox/WebKit 尚未完整验证。

## 工程与自动验证

Ubuntu 22.04；Node.js 20.19+（验证 20.20.2）、npm 10+。

```bash
npm ci
npm run dev
```

若服务器已启动，不重复启动。工程侧负责：

```bash
npm run check
npm run test:e2e
npm run test:production
npm run test:summary
npm audit
```

自动化仅使用公开虚构资料，主浏览器测试固定 **5174 / RecallLab-test**，发布文件资源在 5175 测试；临时浏览器配置不访问日常配置。CI 上传与 SHA 对应的 HTML/JSON/JUnit 报告及失败证据，排除浏览器配置目录。

React、TypeScript、Vite、Dexie、Zod、Papa Parse、PDF.js、Tesseract.js、ts-fsrs、Vitest、Playwright；调度、学习、导入及 PDF/OCR 按需加载。
