# 5—8名目标学习者的轻量用户研究预案

状态：仅预案，2026-10-30；未招募、未访谈、无AI角色模拟人类数据。目标人群：有现成20—100道资料、明确7—14天期限、每天15—45分钟的学习者；不要泛化为所有学科。

先征得自愿同意，使用公开虚构资料作初测；私人材料仅本机，不默认录屏/上传/向模型发送。参与者可随时退出、跳过问题、删除研究记录。记录匿名编号与操作统计，不收集答案正文；任何录制需要另行同意。

1. **任务前5分钟**：平时如何处理现成资料？制卡、安排和复习各花多久？哪一步最烦？过去错过一天如何恢复？不要先展示RecallLab的卖点诱导回答。
2. **首次任务15分钟**：同一份公开69题，设7天/30分钟，准备并开始3题。观察首道有用题时间、材料检查、设置次数、误解、求助。让其解释哪些题可信、哪些需核对。
3. **学习8分钟**：含短答、长答、遗漏、提示；观察能否理解评分来自人工/文字规则，能否纠正判断；不以完成速度推定掌握。
4. **连续性任务5分钟**：刷新恢复输入；修正已学错答案；观察其是否理解新版重学和旧历史；暂停再继续。
5. **隔日/漏日**：自愿参与7天短追踪，记录实际学习与管理时间、是否完成计划及不完成原因。漏日只观察真实发生，不制造内疚。第2天与第7天做独立无提示回忆，预先确定公开标准并保留人工核对来源。
6. **对照**：参与者熟悉的工具/纸质计划。结构化资料允许使用Anki/Mochi等原生CSV；同内容、范围、时间，顺序交叉，记录熟悉程度。区分批量准备和自己概括知识的学习价值。不能拿我们的自动化秒数与其真人分钟比快。
7. **事后访谈**：下一步是否清楚？哪里不知道是否要点击？哪些确认有必要？看到时间风险后想怎么做？是否信任来源/修订？愿意继续用还是原方案？保留反对意见与失败例。

| 记录项         | 口径                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 首道有用题时间 | 从打开开始至来源可信/题干有效/用户可回答，排除安装等待但另记；不删失败样本。   |
| 准备质量       | 人工独立审查来源、题干、答案、必需要点、重复、缺字；检查规则与人类结论分别记。 |
| 每20题负担     | 回答、必要确认、无学习价值设置分别计，不把全部点击混成一数。                   |
| 实际学习耗时   | 人工/参与者记录，有失焦或中断单列；页面活跃秒数只作辅助，不等同专注。          |
| 延迟回忆       | 事先定义必需内容、无提示独立回答，评分者与证据来源明确；样本小不宣称因果最优。 |
| 计划偏差       | 估计时间/覆盖与实际分别记录，说明缺席、资料变化及题目难度。                    |

交付用匿名汇总与逐例失败类型，样本有限只支持迭代判断。未得到这些数据前，对外只描述已实现保护与工作流，不宣传记忆提升/胜过竞品。
