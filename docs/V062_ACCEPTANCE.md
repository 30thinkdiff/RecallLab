# V0.6.2 产品验收

此页描述实际实现，不代表独立审查已完成。交付PR #18依赖#17，不合并既有功能链，不修改main。

## 可以直接体验

打开现有RecallLab网页：

1. 首页“直接创建问答” → 输入问题/标准答案 → “保存并学习”。没有文件也能开始，不要求项目名称或算法参数。
2. 连续录入用“保存并继续添加”，第10题点“保存并学习”；刷新可以恢复未完成输入。
3. 学习中“修改这道题” → 修改 → 保存 → 必要时一次确认 → 继续同一任务下一题。取消不改题目，但不会撤销已看答案的事实。
4. 题库/题目详情可修改问答，高级区域可改要点、提示、助记、重要度与范围。暂停/删除后不继续安排；删除是可恢复的归档，保留历史。
5. 题目详情“编辑学习稿”，或资料页“整理为学习稿”，正文自动保存。原始资料仍可查阅；学习稿与题目互不自动改写。

首次数据库升级先按页面保存保护备份；旧程序不能编辑升级后的数据。新表采用v9迁移，不重写旧答题事件或FSRS。

## 操作负担与证据

| 任务           | PR #17代码与基线测试核对                 | 本轮实际自动化路径                                                        |
| -------------- | ---------------------------------------- | ------------------------------------------------------------------------- |
| 无文件创建首题 | 手动入口先要求建立项目，再到题库添加     | 首页入口、填问题、填答案、保存并学习，共4次表单操作；项目名称/算法设置0项 |
| 连续录入10题   | 每题重新打开添加表单；首题后另选学习入口 | 每题两次内容输入和一次保存；项目/适用设置自动沿用，最后直接开始           |
| 重要更正       | 默认展示技术修订类型及修改原因           | 修改内容、保存、一次确认；辅助信息变动不要求重学确认                      |
| 学习中发现错误 | 需要切换题库管理                         | 本题打开编辑、修改、保存、确认后继续原任务                                |

“输入问题和答案”是内容创作，重要更正确认是证据保护，不能把全部点击都视作无用管理。新自动化测试附首题路径和脚本耗时，**不是用户阅读、思考、学习时间**。未进行本轮真人操作速度或记忆效果测量，也不宣称效率提升百分比。

## 数据与限制

- 正式评分仍需合格回忆证据；AI不自动评分或修改FSRS。纠错记录为旧版本无评分教学事件，新版隔离旧成绩。已看答案暂缓10分钟无提示复测，属于保守规则而非测得的最佳间隔。
- 仅CRLF/LF表示变化等可证明无损的变动可保留状态；核心文字、符号、大小写、空格和必需要点保守处理。历史旧修订原政策为兼容保留，不追溯伪造新证据。
- 学习稿为纯文本，最大100000字；当前采纳方式是明确复制到标准答案并走修订保护，没有富文本、自动同步或AI语义等价判定。
- 冲突保持本页输入、可下载，题目详情可查未提交编辑副本；不会自动合并两处文本。
- 未提交编辑最多100份/12 MiB；备份保留原容量保护（普通128 MiB、去重格式50 MiB、展开128 MiB），没有为本轮进行大备份架构重写。
- 测试使用公开虚构题目与PDF，隔离浏览器数据库；未修改真实学习记录、模型或私人原始资料。未进行新的真实模型评测。

最终类型、Lint、格式、单元、双浏览器、发布版及CI结果见[V062检查点](V062_CHECKPOINTS.md)。完成后停止扩展，等待独立代码审查和真实体验。下一步宜先开展少量目标用户任务测试，再判断是否需要更强的内容辅助，不能凭模拟学习宣称真实效果。
