# 资料导入指南

## 一次导入明确题库

打开 RecallLab，点击“导入资料”，选择文件。预览会显示识别数量、待补全和疑似重复；每页最多展示 10 道，但确认操作会保存全部已选题目。
可编辑问题与答案、取消个别题目，选择已有项目或创建新项目后确认。结果页可直接开始学习，或回项目题库。
预览取消不会写入资料、项目或题目。批量保存失败会整体回滚，不留下前半批数据。

若项目已有未完成轮次，结果页“开始学习（加入本轮新题）”会明确将未加入的新题纳入本轮，保留当前草稿与完成历史。当前题目有版本冲突时需先处理，不能绕过旧保护机制。

## JSON

支持顶层数组，或对象中的 `items` / `questions` 数组。每条必须是对象。

```json
{
  "items": [
    {
      "question": "虚构协议甲是什么？",
      "answer": "标准答案第一点。\n标准答案第二点。",
      "hints": ["提示一", "提示二"],
      "answerCriteria": ["必需要点一", "必需要点二"]
    }
  ]
}
```

问题列名支持 `question`、`问题`、`题目`；答案支持 `answer`、`standardAnswer`、`答案`、`标准答案`。
提示和核对要点可为字符串或字符串数组。还支持 `mnemonics`/`助记`、`confusionWarnings`/`易混提醒`。
不执行文件内容，也不采用题库提供的数据库 ID 覆盖旧实体。

`RecallLabBackup` 文件是完整备份，导入页会拒绝并引导至“备份与恢复”。恢复的替换语义与题库追加不同。

## CSV 与 TSV

第一行必须是问题/答案列名，可用英文或上述中文别名。CSV 支持逗号、分号和制表分隔识别；TSV 固定为制表符。
含逗号、引号或换行的字段必须正确加双引号，字段内双引号写为两个双引号。

```csv
question,answer
"带逗号,的问题","第一行答案
第二行含""引号"""
```

使用 UTF-8（可带 BOM），或带 BOM 的 UTF-16。无法可靠解码时不会强行猜测，请从原软件导出 UTF-8。
Word 文件请先另存为 TXT；本轮不直接读取 DOCX。

## TXT / Markdown

优先识别明确的 Q/A、问/答标记，答案可跨多行：

```text
# 虚构章节
Q: 虚构问题一？
A: 第一要点
第二要点

问：虚构问题二？
答：另一答案。
```

识别 Markdown 标题、“第…章/节/篇”和明确的 Chapter/Section 编号标题。章节来源于实际文字，不是 AI 推断。
未识别的正文会提示人工核对；不会把普通段落冒充成系统生成的题目。

## PDF 与普通正文

1. 上传 PDF，等待逐页提取，先查看页面类型和内容核查。
2. 明确编号/问答会建立候选，保留章节与跨页原文；无需逐题重复录入。可以逐页抽查、修改，核对后一次确认全部已选。待完善题干可先保存，再到项目批量完善；完善前不参与学习或正式调度。
3. 没有明确问答分隔的知识陈述使用不含答案的“待完善题干”占位，答案保留完整原条目；未给答案的问题需补全或取消选择。口诀/解析另放辅助内容，不混入标准答案。
4. 查看可读页/总页、章节、候选、未归类字符、重点核对和跨页条目。未归类原文可展开并定位到页；有可读文字不代表知识已完整提取。
5. 普通教材仍可在原文框拖选文字 →“用选中原文创建问答”→ 填写问题及标准答案。TXT/Markdown 同样可用。

### 扫描与混合图文

页面含图片且缺文字，或图文混合时，可点击“在本机识别图片文字（OCR）”。支持简体中文和英文、多页进度与取消，不上传私人资料。首次加载约 8 MB，可能使用数百 MB 内存；较弱设备可少量分页导入。

识别后必须核对：每页文字标记为 OCR、尚未验证，引擎把握值不是准确率。展开“查看第…页图像，对照 OCR”，再修改候选问题和答案。模糊页重点核对。图文混合页保留原 PDF 文字层，与 OCR 文字分别显示；选中来源保留原识别片段，编辑学习答案不会改写它。

扫描件、空白页、解析异常分开提示。全无内容不能保存为成功资料；缺页/乱码不会静默变成标准答案。图片里的公式、复杂表格、多栏和所有字体仍不保证正确，原文件需要保留。OCR 只是一种候选文本来源，不是系统认证。

页面图像只用于本次导入核对，未保存原文件或图像二进制；保存后仍可查看识别文字、OCR 标记和页码。需要再次核对图像时重新选择原文件。

## 来源、修订与重复

每份资料保存原始提取文本、校验信息、页面和章节。引用保留原文片段和位置；编辑学习答案不修改原文或过去的事件。
学习、题目详情及历史中的来源链接可回到原资料及页码。原文件二进制不在库内，请自行保留文件。

相同问题只被标为“疑似重复”，不同答案尤其需要核对。默认不选这些候选，可明确选择追加；不会自动替换旧题或继承旧成绩。
已有题目的实质性更正仍须通过原修订流程，新知识不会借用旧版掌握结果。

## 当前限额与恢复

- 单次文字题库最多 5 MB / 1000 题；PDF 最多 20 MB / 200 页、200 万提取字符。
- 每道问题最多 5000 字、标准答案最多 20000 字；过长可缩小选文或拆分。
- PDF 普通提取上限 45 秒；本地 OCR 上限 20 页/次、300 秒、400 万像素/页。超时可拆分重试；取消预览不保存。
- OCR 初始化中已开始的资源加载可能继续缓存，就绪的识别任务会终止，不继续写入资料。
- 如果选择文件后出现错误，可重新选择其他文件；不要清除浏览器数据库。
- 导入前后都可使用“备份与恢复”保存外部 JSON。恢复前请确认替换的是当前数据，而非普通追加导入。

## V0.4 导入后的学习

结果页选择“按计划学习新题（FSRS）”，按预算安排适量新题；原完整轮次按钮保留为自由练习。正式复习方式与评分说明见 [FSRS_GUIDE.md](FSRS_GUIDE.md)。编辑候选后重新 OCR/换文件需确认放弃，取消会保留原编辑；批量选择也受保护。

## 可选 AI 辅助整理（V0.5 Alpha）

没有明确问答的普通材料可以先“仅保存资料”，再从结果或资料详情点击“AI 辅助整理”。选择目标、模型和页码范围，检查发送内容并主动同意；候选原文、答案与评分要点分别核对，人工确认后批量保存。清晰编号材料仍优先沿用原来的确定性导入，不需要 AI。

已有题目可在详情中建议评分要点/题干，待完善页支持批量选择。原文背诵答案直接使用来源，既有标准答案保持不变；引用缺失或歧义不能保存。仅排版空白差异可按真实位置还原，不能改动文字/标点或把词边界消掉。OCR 仍未自动验证，AI 不能替代人工核对。详细使用、隐私与模型质量限制见 [AI 指南](AI_GUIDE.md)。

## V0.5.2 分知识整理与审核

普通材料可先仅保存资料，再选择“AI辅助整理→分知识整理”。模型只建议题干，答案和初始核对项保留原文；仍需人工确认题干范围、必要条件和要点。按章节查看缺少候选的单元，可标为暂不制卡，编辑刷新后保留；只重新核对发生变化的条目。重复项比较后跳过，不自动覆盖原题。

明确编号题库仍优先确定性导入，不配置AI也能完成导入、学习及复习。[实际质量与操作对照](evaluations/V052_MODEL_REPORT.md)同时公开改进、失败和未测量的人工作业。
