# V0.6 策略实验、耗时证据与验收边界

## 结论与证据类型

新流程可以按目标与预算自动安排任务，减少逐题管理输入。这里的调度结果是**可重复的程序模拟**，不是实际用户的未来回忆，也不是有对照的学习效果实验。C加入行为耗时估计，尚未稳定优于B，不能宣传已经提高记忆效率或形成个人最优遗忘模型。

- A：保留V0.5.2 planner原规则，到期/复测/重点/新题，2分钟配额与原新题上限。
- B：同一FSRS5.4.2和默认0.90，使用目标/预算/题长要点的通用耗时、补救与覆盖规则。
- C：B加合格行为耗时的中位数收缩估计。记忆算法、评分规则和参数相同，速度不改变记住/忘记。

固定公开虚构题库、30分钟初始预算、种子规则、初始状态、一天一次学习机会；目标调整情景第4天改为15分钟并延长期限。跨2026年纽约秋令时边界，包含增长、缺席和修订。回答依据题号、尝试序号、日期的固定伪随机规则生成，与FSRS预测无关；不同策略选择与次数不同，得到的序列可不同。**模拟器没有经验证的人类遗忘机制**，不能用它证明目标日保持率。

每次作答后B/C重排；A保留当日原队列。模拟作答耗时规则固定，反馈15秒/首次阅读45秒是显式假设；长答案180–320秒，偏慢情景按2.4倍。允许完成已开始的一题，因此实际于模拟中耗费的时间可能超过预算；不会凭预知真实耗时而挑题。输出不包含真实学习内容。

69题考试情景B/C覆盖较多，但经常遗忘情景中的覆盖并不等于掌握。长答案/偏慢情景仍无法全部覆盖；C对超预算没有一致优势，限幅和通用核对/阅读估计仍有偏差。强项的提前曝光减少，但考前两天可有明确标为练习的重点抽查，不能把它误计为正式复习。原始指标见[全部33组结果](../../evaluation/v06/strategy-results.json)，可由`RECALLLAB_WRITE_EVAL=1 npx vitest run src/learning/strategy-experiment.test.ts`重建，普通CI验证保存结果。

通用耗时规则为`clamp(20 + 0.45 × 字符串长度 + 12 × 必需项数, 30, 600)`秒，再加15秒核对、首次45秒阅读；无历史时原文背诵/理解目标额外保守15%。个人估计为35%通用+65%合格中位数，限制在通用0.5—2倍。选择分数综合到期、逾期、最近失败、复测、FSRS预计可提取性、期限与重点，再按耗时平方根归一；预留新题/补救预算，单批最多50。它们是可解释的工程规则，不是理论最优或已验证的人类遗忘规律。

## 真正使用了哪些行为数据

只观察本页的显示、焦点和交互。首次键入是可观察的尝试起点，不声称检测到脑内开始回忆；30秒无活动不继续累计活跃，计时器超过10秒的断档记未知。刷新间隔也是未知，离开20分钟不会成为20分钟活跃作答。历史墙钟耗时不用于训练个人速度。

个人耗时需至少3条同有效状态的合格样本，或同复杂度至少5条且涉及3个有效状态；排除提示/非独立/中断恢复/不可靠计时/无输入核对证据，按中位数向通用估计收缩并限幅。仅调整任务成本；稳定性/难度/保持率参数仍默认。首次阅读、反馈属于估算，已记录活跃也不是全部真实学习时间；跨日未提交作答的活跃总量在最终提交日保守计预算，不伪称逐日精确分账。

FSRS概率标为算法预测，默认0.90是请求保持率，不是已经测得的个人正确率。评分独立保留用户原答、提示/揭晓、核对来源、可选主观感受和实际grade。未知/提示/跳过不伪造成功；独立完整回忆任务遗漏按Again，真实失败不会成为Hard。

## 个人参数优化：本轮有数据和校准方案，没有拟合

继续固定ts-fsrs5.4.2/default-v1。查阅官方5.4.2发布、优化器与Anki文档；当前最新指南已有6.x接口，不能混装到5.4.2。没有安装优化绑定或训练个人参数。高级页面提供证据及描述性校准，没有“个性化已开启”的装饰按钮；当前FSRS核心权重/保持率不提供直接编辑器。

校准从SchedulingLog.before提取答前预测，只纳入当前有效版本、跨日、无提示独立输入、人工核对或严格文字一致且有正式grade的记录；保留合格event IDs、默认参数版本和时间顺序。少于20条不输出分数；达到时的Brier/log-loss及后30%描述仍不构成拟合或优越性结论。单元实际验证after状态不能泄漏答案、旧状态/提示/纯自评/未来时间排除，原始记录不改。

未来拟合须先冻结事件ID、内容与评分质量复核、算法/权重/参数版本、训练/时间后段验证切分；在后续独立回忆上比较默认与候选的Brier、log-loss、分桶校准和样本量/不确定性。样本不足或后段退化保留默认，不能根据偶然波动频繁改参，更不能用答题速度当记忆稳定性。还需要真正前瞻数据，不能把训练拟合改善说成记忆能力提高。

## 操作成本与真实学习效果

Playwright在相同公开题目、输入作答、整体人工核对条件下，实际计数旧版与新版每题操作；目标/导入的一次性设置不计入每题。实际本机计量：旧版6次（4点击/1填答/1下拉选择），新版3次（2点击/1填答），均输入18个字符。分别耗267ms/142ms仅为脚本操作墙钟，不是人类用时。原始记录见[旧版](../../evaluation/v06/interaction-legacy.json)/[新版](../../evaluation/v06/interaction-compact.json)，CI附带自己的计数与脚本墙钟。**脚本不是工程人员或真实用户的阅读/思考时间**。没有真人准备/学习耗时，也没有未来回忆对照，不能宣传提效百分比。

## 当前限制与下一步

没有AI语义判分，没有个人FSRS拟合，不保证考试/全题掌握。开放或长答案仍需一次人工反馈；它不等同机器客观正确率。新目标入口保留旧高级功能；旧正式轮次可保留当前草稿后采用新模式，临时练习不会因此变成正式成绩。重要目标变更/恢复/重排会使过期标签页令牌失效，输入副本仍可在题目详情查看。

预算是混合观测/规则估计，当前题可能超时，后台/未知不作真实学习时长。新界面给出接近预算提醒和暂停入口。时间/范围不足应调整目标，不能以伪造完成应对。活动轮次保留创建时区；已验证本地跨日及纽约夏令时，不声称已完成中途跨国旅行所有情景。

下一阶段应先做自愿、前瞻的耗时与预测校准、题目质量复核；可以逐步增加描述性学习诊断，但暂不据少量数据给能力结论，也不启动复杂Agent或语义自动评分。等待独立代码审查。
