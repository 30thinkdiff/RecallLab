## 调度与证据的可检验边界

| 场景                             | 检查路径/预期                                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 连续正确、失败、提示、临考、缺席 | 现有learning/service、strategy-experiment受控时钟与33组多日策略情景；不修改FSRS5.4.2公式/默认0.90。               |
| 失败/提示刚结束                  | 新完成摘要说明至少10分钟后复测，即使短FSRS间隔还未到；提示不记独立成功。                                          |
| 预算不足/长时间离开              | 原活跃时间和异常值规则保留；新浏览器用受控时钟及持续交互耗尽2分钟预算，跳过一天再恢复，新日预算重算，旧事件不变。 |
| 新增/重要修订/纯格式修订         | 原事务/learningState规则保留；新摘要只看当前有效范围，旧版失败不污染新版；实际当天旧记录仍在总记录数中。          |
| 主观高分、跳过、无尝试           | 不清除已有合格困难证据，不制造虚假成功/失败；原评分映射仍由可信事件控制。                                         |
| 多标签页/刷新/恢复/离线          | 原CAS、草稿、完整恢复及独立浏览器重启流程保留；同步修复另测通知竞态。                                             |

完成摘要只读；按项目查询，未给首页增加全库历史加载。显示的次数包括重复/当天旧版，薄弱是当前有效版本最近一次合格核对的遗漏/错误/提示，不是机器语义测量或掌握概率。

## 假设结论与下一步

- **A 制卡更快**：没有可比的竞品全旅程/真人证据。官方工具已有CSV导入，不能拿手抄69遍作稻草人。内部导航更少，首题脚本时间未改善。
- **B 管理更少**：保存目标的续学2→1、准备4→3得到程序任务支持；每20题管理已0→0。真人是否省心、是否执行计划仍未测。
- **C 修订更可靠**：程序测试支持我们的证据隔离与恢复行为；没有做竞品同条件修订黑盒比较，不称行业最可靠。

优先进行5—8名目标学习者的真实首次导入/续学/漏日/一周延迟回忆研究。依据真实阻碍再选择UX或来源/题干质量改进；如果可靠题仍难准备，先修内容质量。暂不更改FSRS算法、个人拟合或扩张AI导师/学习诊断。没有招募或访谈发生，本轮到此等待审查。
