# 直接体验V0.6.1

打开本机[RecallLab](http://127.0.0.1:5173/)。不需要登录、AI服务或自行构建。体验在本机保存，重要学习记录仍建议在高级功能中备份。

1. **开始一份资料**：点击“创建学习任务”，选择已有题库或PDF。题库名称由文件名带入，不需要先建项目；需要追加旧题库时可展开保存位置。
2. **抽查后确认**：查看题干、答案、来源和提醒。主确认按钮在候选列表前；缺字段时不能直接保存，可选择字段完整的非重复题目。待完善题干可保留为草稿，其余合格题先学。跳过的数量会明确显示，原始资料仍保存。
3. **只设主要目标**：完整导入后直接进入目标页，选择目标、截止日和每天时间（例如7天/30分钟），看建议后开始。不必设置遗忘曲线或逐题复习次数；章节、新题上限等保留在高级设置。
4. **回忆并核对**：先输入，再提交。短答案文字一致时可采纳或更正；长答案用简洁人工确认，也可展开逐项核对。仍需确认正确性，不用每题再填0—4自评。提示后需要无提示复测，错误不会被高自评覆盖。
5. **随时停，轻松继续**：暂停会保留草稿。已设目标的任务，从首页“继续今天的学习”直接恢复；没有到期任务时会显示下一次安排。漏一天回来按当前进度重排，不要求刷完所有积压。发现题目有错可先标记暂不学习，再从题库更正，旧记录保留、新内容重新安排。
6. **结束只看下一步**：查看今天实际练习、当前仍薄弱内容、下次复习和时间风险；记录与题库管理可以展开。次数不是掌握率，估算可行也不保证考试通过。

可以先体验“导入→完成几题→暂停续学→看下一步”这一个任务。大量兼容、并发、迁移和浏览器回归由工程自动完成，不需要你运行测试。

AI依然可选；未经核对的OCR、AI建议和不完整题目不会因流程变短就自动变成可靠学习证据。没有AI，也能导入、学习、复习、查看历史与备份。
