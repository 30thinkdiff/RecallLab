## B · 结构化题库导入

- 支持 JSON 数组/items/questions、带引号及多行字段的 CSV/TSV、明确 Q/A 或问/答格式的 TXT/Markdown。
- 上传→解析→可编辑预览→确认→学习；缺字段阻止提交，疑似重复默认不选，仍导入需明确确认。
- 选择已有项目或新项目，事务内追加资料/知识单元/题目/初始修订，不清除已有题库与历史；同一次确认可幂等重试。
- 未知结构只展示原文，允许选文手工制卡，不编造问题。资料库与题目、学习、历史的来源入口已连通。
- 预览取消不写数据库；模拟中途写入失败时项目、资料和全部题目回滚。
- 75 项单元/组件、类型/Lint/格式/构建通过；8 项新增浏览器验收通过，包括 69 题批量导入及基本手机布局。
- 导入页面按需加载，避免把解析依赖加入初始页面。入口：项目题库或侧栏“导入资料”；当前不要求用户执行技术测试。

## D · PDF 基础解析

- PDF.js 在本地 Worker 中逐页提取，保留页码、实际文本、章节及全局位置；选择原文后填写问题并确认制卡。
- 无文字、损坏、乱码或缺页有明确提示；部分可读 PDF 保留不完整状态并要求人工核对，无 OCR，不生成假问题或答案。
- 当前仅保留提取文字与文件校验信息，不保存二进制原文件，不渲染原 PDF 版式/图片，不执行 PDF 脚本。
- PDF 支持 20 MB/200 页，提取超时可重新选择或拆分。PDF 组件按需加载，无 CDN 或文件上传。
- PDF.js 5.6.205 的高危回归已在交付前排除，采用未受影响且兼容 Node20 的 5.5.207；最终全量/生产依赖审计均为 0。
- 78 项单元/组件、类型/Lint/格式/夹具/生产构建通过；完整 32 项 Chromium 回归通过（含原有 18 项）。
- 新增实际双页文本 PDF、模拟扫描件、文本与图片混合、损坏 PDF；验证第二页来源、改答案保留原文、备份恢复、普通文字选文及基本手机布局。
