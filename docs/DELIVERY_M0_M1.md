# M0/M1 交付报告

日期：2026-10-27。版本：0.1.0，尚未发布稳定版本或打 Tag。

## 1. 本阶段实现了什么

M0 提供本地可运行首页、导航、热更新与基本工程检查。
M1 完成真实学习闭环：项目管理 → 题库管理 → 快速回忆/输入作答 → 提示与揭晓 → 自行核对和五级自评 → 追加事件 → 下一题 → 本地恢复。
另提供题目搜索、近期记录、自评概览与历史快照详情。

## 2. 如何亲自体验

```bash
cd /home/hhd/recalllib
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。如果本轮启动的服务器仍在运行，可直接打开，无需再运行第二个服务器。
创建项目并添加 10 道自己的问答题，分别尝试快速回忆、输入答案、逐条提示、直接揭晓和跳过。
完成一轮后查看历史，再刷新、关闭并重开同一浏览器验证数据恢复。
中途离开后可从项目“继续学习”。已开始的轮次固定使用开始时的题目快照。

预期：答题前看不到标准答案；揭晓后原始输入锁定；人工核对和自评各自保留；重复提交不跳过下一题。

## 3. 代码修改情况

- `src/App.tsx`：应用壳、Hash 路由、响应式工作台入口。
- `src/features`：项目/题目表单、概览/题库/历史与学习流程。
- `src/domain`：严格模型、Zod 输入校验、学习事件构建及相应测试。
- `src/persistence`：Dexie schema v1、事务仓库、并发去重、题目修订和快照。
- `src/components`：弹窗、异步反馈与数据读取错误边界。
- `tests/e2e`：真实浏览器验收。
- 工程配置、锁文件、CI、README、产品/架构/进度/变更文档。

决策：采用推荐栈中的 React、TypeScript、Vite 和 Dexie；初期以原生 CSS、dialog 与 Hash 路由控制复杂度，未加入 Tailwind、大型组件库、服务端或未使用的模块。
保留本机 Node 20.20.2，未升级全局环境。数据按 origin 隔离，因此固定用开发端口 5173。

- `npm run check`：类型、Lint、格式、23 个单元/组件测试、生产构建通过。
