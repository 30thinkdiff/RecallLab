打开 http://127.0.0.1:5173 → 导入并保存资料 → AI辅助整理。查看模型状态，选择目标，主动启用并同意生成。对照引用修改题干或要点，等“草稿已保存”后刷新；也可关闭重开，从“AI整理草稿”继续。核对候选与完整性后确认，开始正式复习。

# V0.5 Alpha 产品验收说明

打开 <http://127.0.0.1:5173>。无需安装工具、构建或执行测试；下列是少量产品体验，其余回归由工程侧完成。

## 1. 导入并检查资料

“导入资料”→选择 PDF 或题库→检查原文和候选→确认导入→返回项目。
若有“待完善题干”，使用批量管理补写合适的问题；这些内容保留原答案和来源，完善前不进入学习。
“题目质量核对”集中显示规则提示，可编辑答案/核对要点，并选中已经对照原资料检查的版本。人工确认不会把 OCR 原文变成机器验证结果，也不能绕过无效题干。

## 2. 连续复习几道题

“今日复习”→设置每天 30 分钟→开始。先独立回忆、输入回答，再揭晓。
有核对要点时可以选择“逐项核对全部必需要点”，逐项标记正确、遗漏、错误或无法确认；也可使用简洁的整体人工判断。
全部必需内容确认正确才允许成功评分，遗漏/错误不会因自评“完全掌握”而通过。提示或未核对只安排无提示复测。
随时暂停返回，下次继续原回答和核对选择，不必做完整套题才退出。

## 3. 查看结果与来源

保存后看本次依据和下次时间；“学习记录”详情保留原回答、当时答案、逐项人工标记和来源。
在项目更正错误答案后，旧记录仍在，新版需重新学习，不继承失效成绩。
“备份与恢复”包含调度和逐项证据；恢复会替换当前内容，先按页面下载保护备份。

## 离线与限制

发布版首次完整加载，看到“基础学习已准备离线使用”后，可在同一浏览器/地址离线重新打开。学习数据仍在当前浏览器，不是云备份；清除网站数据会同时删除记录和缓存。
核心页面和调度代码预缓存；PDF 字体/CMap 与 OCR 模型按需缓存，未用过的解析资源未必可在离线状态首次使用。开发预览不安装持久缓存。

评价仍由人核对，系统没有语义自动判题；AI 可以提出评分要点建议，只有人工确认后生效。预算按每题约 2 分钟估算，不是实测专注时间；原作答耗时包含暂停，不用于推断个人能力。

69 条真实 PDF 中有 7 条需人工完善题干；不能为了凑题数让它们自动进入正式复习。建议先用已经核对的条目体验，再完善其余内容。

## 4. 可选 AI 辅助整理

首次升级时按页面下载保护备份并继续；不要用旧程序编辑已经升级的资料。

导入一份普通笔记或 PDF → 核对提取文字并保存（没有明确题目时选“仅保存资料”）→ 点击“AI 辅助整理” → 选择学习目标 → 启用本次辅助并查看发送内容 → 同意使用预设本机模型 → 生成候选。

本机 CPU 模型本轮已由工程侧准备，不需要购买 API。预览中分别查看原文、问题、拟保存答案和评分要点，修改/删除/合并后，勾选需要的候选及两项核对确认，再保存并开始正式复习。已有题目也可从详情提出要点/题干建议；标准答案不被 AI 改写。

Mock 是模拟演示，不能用来判断模型效果。真实小模型可能遗漏、引用错误或超时，引用不足无法保存；不要把“生成结束”当作内容完整。原文背诵会直接采用实际引用原文。未经确认的草稿不进入题库，刷新前注意草稿提示。

工程侧已经完成全部大量测试；用户只需体验导入、核对候选和连续学习几道题。最终测试数、精确 commit 与 CI 状态统一记录在 [PR #11 交付报告](https://github.com/30thinkdiff/RecallLab/pull/11)，无须运行测试命令。
