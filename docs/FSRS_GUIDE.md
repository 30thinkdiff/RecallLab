# V0.4 间隔复习体验指南

打开 <http://127.0.0.1:5173>，无需运行构建或测试。首次发现旧数据时，先点击下载升级前备份，再升级继续；原有记录保留。

## 从自己的题库开始

1. 导入资料并预览确认。没有合适题干的知识陈述保存为“待完善题干”，不会直接用于学习；在项目的“批量管理待完善题干”中补写问题，可以一次保存多条。
2. 在“今日复习”选择项目，点击“设置学习预算与目标”，例如每天 30 分钟、目标日期和优先级。默认每日最多引入 10 道新题，可修改。
3. 选择今日计划或只学新题，开始本次复习。导入完成页也可直接选择“按计划学习新题（FSRS）”。
4. 先独立回忆，输入回答或明确记录口头回忆尝试，再揭晓答案、核对必需内容。五级主观掌握感单独保留。
5. 保存后会看到评分依据与下次时间。随时“暂停并返回今日复习”，下次继续原计划和草稿；想换范围，可先结束本轮，历史不会被清除。

传统完整轮次继续保留，作为自由练习，不自动成为正式间隔复习。已有旧学习记录的题目也从新调度开始，不把旧自评推算成不存在的 FSRS 成绩。

## 系统如何安排

| 本次证据                                         | 安排                                               |
| ------------------------------------------------ | -------------------------------------------------- |
| 无提示、揭晓前有回忆尝试、你核对全部必需内容正确 | 按实际难度 Hard / Good / Easy，默认 Good           |
| 无提示独立尝试失败                               | Again，重新学习；不会因自评高而改成 Hard           |
| 完整复述遗漏必需内容                             | Again；部分正确不自动算通过                        |
| 使用提示、直接看答案或未核对                     | 不更新 FSRS 长期卡片；安排约 10 分钟后的无提示复测 |
| 跳过                                             | 不推断遗忘，不更新 FSRS，不扣题数配额              |
| 未到期加练、自选临时练习、预算外明确加练         | 记录练习，保留评价来源，不更新长期状态             |

口头回忆仍是用户自报；输入作答后由用户人工核对。系统没有自动验证正确性，也不会把“感觉完全掌握”显示成客观测量。

当前自由回忆题采用“必需内容全部满足”的成功标准。若有不要求记住的解释或例子，请不要把它们设为必需核对项；认为仍遗漏必需内容时选部分正确/错误，不以熟悉感替代核对。

## 今日计划与预算

队列优先到期→无提示复测→重点→适量新题。长期复习按本地到期日进入今日，分钟级学习/补救到点后开放；首页还显示今日稍后到点的内容。目标日期前 7 天，同级任务优先近期薄弱内容，提前练习不更改长期安排。

预算按每题约 2 分钟估算配额，不是测得的净学习时长。30 分钟通常最多安排 15 次练习，新题还受每日上限约束。预算耗尽可暂停或选择明确的临时加练；临时加练每轮最多 100 题，不更新长期状态。到期任务没有被清除，之后仍可查看和继续安排。

可选到期、新题、薄弱项、章节或自选临时练习；各题可设为重点。未完成计划优先恢复原顺序与范围，跨日不自动丢弃旧草稿；若要完全重排，先结束原轮次，再打开今日计划。

## 修订、统计与备份

修正错误答案或完善实质性题干会产生新学习状态，旧事件和原答案仍保留。纯格式变化经过原保护校验后可保留已有状态，不能只靠选择“格式修改”就继承变更过的答案。

“无提示人工核对正确率”只统计当前有效版本、保留输入回答且无提示的人工核对。口头自报与提示后成功另列；没有样本时明确提示，不显示伪造正确率或个人记忆概率。实际练习工作量仍包含真实发生的旧版记录。

FSRS 使用 ts-fsrs 5.4.2 的默认参数，目标保持率 90% 是通用初始设置，没有训练个人最优参数，不保证效果最优。参见 [官方项目](https://github.com/open-spaced-repetition/ts-fsrs) 与 [Anki FSRS 说明](https://docs.ankiweb.net/deck-options.html#fsrs)。

完整备份为数据库 v4，包含记忆状态与全部调度决策。仍可恢复 v1/v2/v3 备份，但旧备份没有正式调度数据，会从新评价开始；恢复前会保留当前完整保护副本。普通题库导入始终只是追加。

如果揭晓后暂停、隔天才保存评价，系统使用当时保留的回忆时间安排间隔，不会把晚保存的这一天当作额外保持成功；若原安排已过期，会重新列为到期。工作量按回忆发生日汇总，旧记录缺少此时间时保留其原保存时间，不伪造更早的作答时刻。预算也计入当天已保存的传统轮次练习，但这些记录不会被转换成 FSRS 评分。
