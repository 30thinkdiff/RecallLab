# RecallLab 产品规格 · 第二轮

RecallLab — An Evidence-Driven Adaptive Learning System，中文名记忆实验室。
长期方向是依据实际学习证据调整学习过程；当前交付是可靠的主动回忆、知识版本与学习历史工具，尚未宣称实现科学自适应模型。

## 核心流程

项目 → 手工问答 → 无提示尝试或逐条提示 → 揭晓 → 自行核对与主观评价 → 保存事件 → 更新轮次或继续 → 回看证据。
资料变化时：明确修订类型与原因 → 建立不可变版本 → 判断学习影响 → 当前题冲突处理 → 新版重新学习或继承已声明无影响的证据。

## 不变量

1. 历史问答、作答、条件与评分不追溯改写。
2. 当前正常练习只能对当前有效、未归档的题目版本评分。
3. 实质性更正及知识替换需要重新学习，旧成绩保留但不代表新版表现。
4. 格式修改及明确不影响考核的澄清可继承有效证据，系统不自动推断语义等价。
5. 新增题目须用户选择加入本轮，不打乱当前回答。
6. 更新计划保留完成前缀，移除归档任务不伪造学习事件。
7. 过期草稿不能静默覆盖；揭晓后证据锁定；同一位置最多一条正式事件。
8. 迁移和恢复有备份与事务回滚，不通过清库修复失败。

## 功能与验收

- 项目、手工问答管理，题目来源、核对要点、多提示、助记、易混提醒。
- 快速回忆与输入作答，五级主观评价、人工正确性核对、信心、跳过、草稿恢复。
- 标准答案编辑有保守默认、修改原因和乐观并发检查。
- 当前题修改时显示冲突，暂停评分，可保留旧输入并载入新版重答。
- 轮次支持加入新题/下轮再学、更新待答、剩余列表、结束和重新开始。
- 学习中归档，归档内容可查看及恢复。
- 按时间和按题目查看完整事件，比较版本差异、修订分布和当前有效证据。
- 实际次数、结果分布、自评点图；低样本明确说明，不拟合记忆趋势。
- 完整 JSON 备份、结构/引用校验、预览确认、事务恢复、失败回滚、保护副本下载。

重点验收：纠正练习过多次的错误答案、2 题开学后加入 20 题、两页面竞争写入、完整版本历史、CI 自动回归。场景由 [TESTING.md](TESTING.md) 的 A–N 矩阵覆盖。

## 证据说明

人工核对正确/部分正确/不正确/未核对与主观 0–4 分开保存，允许矛盾。
快速回忆没有采集完整回答，正确性声明只属自评；输入作答保留原文，由用户人工核对。
“无提示回忆尝试”不表示正确。直接揭晓、提示后正确、无提示人工核对正确分别可追溯。
提示比例以非跳过练习为分母，时间含离开页面的暂停，不视为净答题时间。
当前有效统计按学习状态筛选，不把失效旧版成功计入新版掌握。
存在学习过旧答案的风险不等于已形成错误记忆，不下此类诊断。

## 本轮范围之外

完整 FSRS、AI 制卡/语义评分、PDF、云同步、账户、复杂个体记忆模型、多人协作及大规模策略优化。
不为辅助审查强行部署公开站点；本地隔离测试和 GitHub 报告是本轮审查入口。
A–E 完成后停止扩展，等待体验和独立审查。
