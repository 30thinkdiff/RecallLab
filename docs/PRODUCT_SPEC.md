# RecallLab 产品规格 · M0/M1

RecallLab — An Evidence-Driven Adaptive Learning System，中文名记忆实验室。
长期定位是以个人资料为来源、依据实际学习证据持续调整练习过程的学习系统。
当前交付是可用的主动回忆工具，自适应策略仍属后续待验证方向。

## 用户场景与流程

用户为考试或长期学习创建项目，手工整理问题与标准答案，进行主动回忆、自行核对与评价，之后回看学习证据。

创建项目 → 录入问答 → 选择作答模式 → 独立尝试或查看提示 → 揭晓 → 自行核对 → 五级自评 → 保存事件 → 下一题。

## 本轮要求

- 项目创建、编辑、删除，记录目标日期和每日时间计划。
- 题库查看、问题搜索、手工增删改问答。
- 自由回忆题支持快速回忆和输入作答。
- 答案揭晓前不显示标准答案、核对要点、助记和易混信息。
- 用户主动请求提示时逐条展示并留存使用数量。
- 输入作答保留原文，揭晓后锁定；快速回忆明确未采集完整回答。
- 自行核对正确、部分正确、不正确、未核对与五级主观掌握评价分别记录。
- 跳过不生成掌握评分，也不伪造成功回忆。
- 记录揭晓前信心（可选）、回忆条件、回答方式、用时和快照。
- 提交事务保证一个队列位置只对应一个事件，避免双击造成重复计数或跳题。
- 浏览器本地持久化与中途续学；错误不自动清空数据库。
- 桌面与手机可用，表单有标签，弹窗支持原生键盘焦点管理。

## 证据含义

五级自评为 0 完全不会、1 只有印象、2 会一部分、3 基本掌握、4 完全掌握。
高自评分不自动转换成客观正确。所有核对由用户完成；本版没有自动语义评分。
“无提示回忆尝试”只描述是否在无提示条件下尝试，不表示回忆成功。
快速回忆的正确性声明标记为自评；输入作答的核对标记为用户人工核对。
直接揭晓保留为直接揭晓，不根据后续高自评反推独立回忆。

概览中的已学习题目指当前题库内有至少一次非跳过记录的不同题目。
主观评价分布只统计当前题库中每题最近一次非空自评，不表示算法预测。

## MVP 验收

在 Ubuntu 22.04 启动本地服务器，通过浏览器创建项目，添加 10 道题，完成一轮学习，
刷新、关闭并重开浏览器后，仍可查看题目和历史。不同项目内容隔离，编辑答案不改变既有历史。
本轮通过自动化覆盖上述场景，仍需用户体验和独立代码审查。

## 暂不包含

FSRS 与到期复习、文件导入与 JSON 备份、自动评分、AI、自适应干预、延迟测试分析、登录、云同步、离线 PWA。
每日时间与目标日期只是用户计划，不生成尚未验证的学习量建议。
M0/M1 完成后停止扩展，后续范围由体验和审查决定。
