# 69题、7天、每天30分钟 · 用户任务与V0.6.1范围

审查日2026-10-30；代码基线PR #15 / 7d1df80224b562c8836763679bb9332d8f39503b。竞品证据另见[产品研究](PRODUCT_COMPETITIVE_REVIEW.md)。以下“用户”是目标任务定义，不是已完成的真人访谈。

## 真正任务与可替代方式

把已有69题在有限时间内变成可执行的回忆任务，知道今天做什么、错了怎么补、漏一天怎么办、改答案后什么还可信。成功不是上传69条或刷完一轮，而是延迟无提示回忆、覆盖必需知识且学习负担可承受。

替代方式：纸质题库自己打勾；日历/表格安排；Anki/Mochi直接CSV批量导入；RemNote/Knowt/StudyFetch的考试计划；直接用原资料反复自测。成熟工具有批量导入，不能假设它们都要手抄69张。

V0.6基线：创建学习任务→选文件→核对候选及来源→列表底部确认→导入完成→再点目标入口→学习目标/日期/时间→长建议与高级设置后开始→回答/揭晓→简洁核对并继续。下次首页继续先回目标页再点继续。内容修订及不可靠题隔离已存在，不重做算法。

## 需求层次

- **必须**：来源可查、有效题能学、学习事件/原始回答持久保存、真实失败/提示有保守安排、修订隔离旧状态、自动安排且允许暂停、备份恢复。
- **应该**：少设置、确认后安全推进、保留已设目标直接续学、缺席按当前情况重排、完成后清楚下一步、风险题集中核对、窄屏一致。
- **以后**：复杂AI导师、知识图谱、个人强化学习、社交/积分。本轮不做。

## 测量与证据界限

`tests/e2e/product-journey.spec.ts`在改UI前以baseline分支路径实际跑3次，同一Chrome/1440×1000、同一69条自制公开问答、7天期限、30分钟。题目为短答案、明确来源，无AI；后续用同一脚本和设备测candidate。原始结果在evaluation/v061，CI附JSON。计时从首次打开到有效首题、首条记录；这是脚本操作时间，没有人类阅读/理解/回忆耗时，不得宣称用户效率提升百分比。

每20题分别计：20次回答、20次提交揭晓、20次正确性确认；额外管理操作基线已为0，本轮不追求取消确认。首题前准备动作和目标要求分开，页面滚动单独计，不把一切点击都叫负担。程序质量检查仅能验证给定虚构标准、引用与排除风险；不等于所有教材语义正确率。

Schedule Reliability沿用受控时钟服务测试和多日模拟（持续正确/失败/提示、缺席、临考、预算、内容修订），补默认流程回归。没有真人延迟回忆数据，不给出记忆效果提升。

## 三个差异化假设

| 假设                   | 基线与可观察指标                                                                                                     | 本轮能验证/不能验证                                                                              |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| A 结构化资料准备更快   | 同一现成资料比较导入/人工整理，首道有效题时间、完整题数、修订量与来源可信；外部工具应使用其原生CSV而非强迫手工69遍。 | 测内部V0.6→V0.6.1同任务导航及可靠题可学；没有可比登录竞品全旅程/真人时间，**未证实比竞品更快**。 |
| B 更少计划管理         | 已保存目标后的续学步骤、每20题管理操作、漏一天无需人工重排。                                                         | 可测导航2→1及20题管理0→0；真人是否觉得更省心未验证。                                             |
| C 修订/证据/截止更可靠 | 相同错误答案修订、旧草稿、跨页与新期限；检查事件不变、旧状态隔离、新版重学、计划解释。                               | 可重复程序测试证明我们的保护行为，未做竞品同等黑盒比较，不能宣称行业最可靠。                     |

真实效果后续指标：延迟24小时/7天无提示回忆；每有效学习分钟的知识覆盖；计划执行/缺席恢复成本；预测与实际差异。完整测试方案见[真实用户研究预案](USER_STUDY_PLAN.md)，没有已经招募/访谈的人数。
