### 可执行的整合方案（等待用户授权，未执行）

2. 每合并一个后，将紧接的下一个 PR base 改为 main，核对仅含该阶段差异、无意外新提交与冲突，等待该 base 下最新 CI 通过，再合并。若 head 变化、CI 失败、出现冲突或新审查问题则停止整合，自行修复普通工程问题后重新验证。
