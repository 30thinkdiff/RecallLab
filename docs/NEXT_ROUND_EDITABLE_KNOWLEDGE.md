## 产品对象与默认路径

核心对象是用户想掌握的知识和练习题。文件是可选来源；不上传文件、不启用AI，也应能开始。

默认路径：**创建或导入知识 → 准备可用题目 → 开始学习 → 自动安排复习**。用户可选择直接写问答、粘贴知识/笔记或上传文件；无需先理解项目、知识单元、修订类型或FSRS。

默认新建/编辑只展示问题、标准答案和保存/取消；创建后提供保存并学习、继续新增等明确行动。目标、提示、要点、助记、来源、重要程度和范围可按需展开；必要的知识核对与影响确认保留，不强迫逐题填写管理参数。没有完整有效题干/答案的内容可保存为学习稿或待完善，其他可靠题可先学。

用户始终可新增、修改、暂停/恢复、归档题目，编辑题干、标准答案、提示、核对要点和助记，调整重要程度与是否纳入当前范围。高级能力保留，入口采用渐进展示。

## 优先实施的三条路径

### 1. 直接创建与连续新增

从主要入口直接填写问题/答案；无现有题库时自动建立必要容器，名称和目标可稍后修改。有现有范围时采用合理默认，用户可展开调整。支持保存并学习、保存并再建一道；不要求每道题重新选择目标或重要程度。没有期限的临时内容采用可解释的通用滚动安排，不强制先填写考试日期；同一处可修改目标和时间预算。

明确问答粘贴走原确定性解析与批量预览，确认后事务写入。普通笔记先保留为学习稿；缺问题或答案时提示补全，不虚构标准答案。手动内容标为用户创建/粘贴，不伪造文件名、PDF页码或原文出处。内部复用File接口不改变其真实来源身份。

### 2. 简洁编辑与自动影响判断

默认只有问题/标准答案，保存前给出简短影响说明。提示、必需要点、助记、易混提醒、学习目标、来源及范围放在展开区。用户不必选择内部修订类型、填写版本ID或撰写技术性修改原因；系统生成的审计说明明确标注为系统记录，用户原因可选，不冒充用户原话。

只有确定性规则可证明不影响正确性标准时才保留有效记忆；含义无法可靠判断则默认重新学习，提供一次简短确认。AI不得自行认定重要更正不影响记忆。必要比较在保存事务中执行，过期页面不能用旧答案覆盖新答案。

### 3. 当前学习题内快速纠错

在当前题打开简洁编辑层，保留任务位置与原始回答；编辑时间不计作独立回忆时间。保存后原位显示新内容和简明安排，无需退出到项目管理。

- 重要更正：保存不可变旧修订/事件，创建新版有效状态，自动安排新版；本次按旧版作出的回答不能直接算新版成功。
- 原回答有价值则保护为旧版草稿/历史证据，不自动填进新版后当作新回忆。可查看保留内容。
- 编辑界面若会显示尚未揭晓的答案，**先记录真实答案暴露，再展示答案**。即使取消，也不能把已看答案恢复成未看答案；不自动制造失败评分或更新FSRS。
- 取消编辑：题目、学习稿、修订和记忆状态不变；保留原输入。已发生的答案/提示暴露属于真实尝试事实，不能随取消抹去。单纯开关编辑不新增一次答题事件。
- 真异页冲突：保留本地未保存编辑，提供载入最新/对照恢复，不能静默覆盖或丢失。

## 修改后的处理规则

| 修改                                       | 默认处理                                                                    | 用户需要做什么                                           |
| ------------------------------------------ | --------------------------------------------------------------------------- | -------------------------------------------------------- |
| 无变化保存                                 | 不创建无意义修订/调度日志。                                                 | 直接返回。                                               |
| 可证明的纯显示排版或无损表示变化           | 保留有效状态；必要时保留修订审计。                                          | 无须了解修订类型。                                       |
| 问题、标准答案、必需要点或题目考核目标改变 | 保留历史，新有效状态，按新题/重学安排。                                     | 一次简短影响确认，例如“更新后重新安排学习，旧记录保留”。 |
| 仅提示、助记等辅助内容变化                 | 不改成功标准时保留状态；以后使用提示仍记录真实提示事实。                    | 正常保存，复杂项按需展开。                               |
| 新增有效题                                 | 纳入后续自动计划，遵守预算/新题限制；不要求先刷完整套。                     | 保存即可，必要核对不省。                                 |
| 暂停/归档                                  | 移出后续队列，保留题目/修订/事件/调度历史，允许恢复。                       | 明确暂停/删除动作；永久删除不在本轮。                    |
| 调整重要程度/章节/范围/期限/每天时间       | 只重算受影响计划，保留合格记忆状态和其他题目的证据。                        | 可选设置，不逐题强迫填写。                               |
| 修改知识要求/学习目标                      | 区分计划偏好与正确性标准；影响后者时只隔离相关有效状态。                    | 无法可靠判断时一次保守确认。                             |
| 修改学习稿                                 | 不直接覆盖题目标准答案；受影响的派生候选/引用版本需要核对，其他题继续可学。 | 明确采纳为题目内容时再保存/确认。                        |

不能通过删除所有空格、标点或统一大小写来普遍证明“仅格式”：代码缩进、英文词间空格、数字/否定词、公式和严格复述可能改变含义。当前comparable规则需在下一轮收紧/验证；设计不把已有归一化规则当语义等价证明。不能只靠一个“保留成绩”复选框绕过服务端保护。

## 原始来源、学习稿、练习题

| 对象         | 用户权利与证据边界                                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 原始来源快照 | 原文件、提取文本及页码/引用保留；修正提取错误时新建可追溯版本，不覆盖旧引用。来源也可为用户输入快照；没有文件时不要求伪造一个。      |
| 可编辑学习稿 | 用户可补充、整理、纠正。来源引文、用户添加、可选AI建议分开标识；保留版本与来源位置，用户补充不能显示为“PDF原文”。无需修改PDF再上传。 |
| 独立练习题   | 问题、确认答案和要点可单独编辑；引用原文/学习稿的具体版本。修改任一层不静默覆盖另一层，不变更旧答题快照。                            |

先对现有KnowledgeUnit与PracticeItem做最小必要解耦，不一次性重建笔记系统、图谱或全部文档编辑器。学习稿不成为每次创建题目的额外表单。若需要数据库升级，先保护旧备份，保留version(1)，新增正式版本，验证旧数据/备份、回滚及不可变历史；本次未选择或实施新数据库版本。

所有草稿写入、题目保存和计划更新均验证基础版本；批量写入原子完成并防重复提交。归档、暂停和恢复也需校验基础版本，避免旧页面静默停用已在另一页面更正的题目。用户补充或资料版本变化后，旧候选不得绕过来源有效性检查。

## 操作负担与停止条件

下一轮用同一公开资料、同设备和同任务实测现有入口（包括PR #17实际可用版本）与改进版，不能用旧的不利入口冒充最新基线。当前未测真人编辑时间，不给出减少百分比。

以下是**设计目标，尚未达成测量结果**，从相关页面已打开计，不含真正思考/作答：

- 首页创建首道有效问答并学习：1次入口、2次核心填写、1次“保存并学习”；无项目名称/修订/算法必填。初次自选期限等意图输入另列，不摊到每题。
- 连续新增：每题2次核心填写、1次保存并继续；不重复配置范围/目标。
- 当前题更正答案：1次打开编辑、1次答案修改、1次保存，重要更正最多再1次简短确认；不要求离开当前任务。
- 粘贴明确问答：粘贴、解析/预览、必要确认分别计。普通段落的必要制题与来源核对单列，不为了少点击而伪造题目。

分别记录学习回答、必要正确性/影响确认、纯管理操作、页面跳转、错误恢复及脚本耗时；用户阅读/理解与真人时间另测。不能把脚本速度当真人效率，也不能把所有点击都视为负担。

优先交付创建/连续新增、简洁编辑、学习内纠错及最小学习稿解耦；稳定后再考虑批量编辑、语义去重合并和新题型。每步提交并运行对应类型/Lint/单元/浏览器/备份回归。保留FSRS5.4.2、真实学习证据、本地优先与AI可选；不开发AI自动判分、复杂Agent或云同步。未经授权不合并任何既有/新PR，完成后等待独立审查。
